NIVELL 4 · LES DADES DEL JOC

Funcions i les seves característiques

ConcepteLa reglaUn exemple
FuncióA cada x li correspon una sola y. x: variable independent · y: dependent.f(x) = 3x + 10 → f(5) = 25
4 representacionsEnunciat, taula, gràfica i fórmula.«10 monedes i 3 més per minut» → f(x) = 3x + 10
DominiEls valors de x que tenen imatge. No es pot dividir per 0 ni fer l'arrel d'un negatiu. Mira també el context.f(x) = 1x − 2 → Dom = ℝ − {2}
RecorregutEls valors de y que pren la funció.f(x) = x2 → Im = [0, +∞)
Punts de tallEix Y: x = 0 → (0, f(0)) · Eix X: resol f(x) = 0.f(x) = 2x − 6 → (0, −6) i (3, 0)
CreixementIntervals de x on la gràfica puja (creixent) o baixa (decreixent), d'esquerra a dreta.Puja de x = 0 a x = 3 → creixent a (0, 3)
Màxims i mínimsRelatiu: on passa de créixer a decréixer (màxim) o al revés (mínim). Absolut: el valor més alt o més baix.Màxim a (3, 6): a x = 3, y = 6
TVMTVM [a, b] = f(b) − f(a)b − a. És la velocitat de canvi.f(x) = x2: TVM [1, 3] = 9 − 13 − 1 = 4
ContinuïtatContínua: es dibuixa sense aixecar el llapis. Si fa un salt, és discontínua.Preu per trams: salt a 100 MB
NIVELL 5 · ELS MODELS DEL JOC

Tipus de funcions

ConcepteLa reglaUn exemple
Funció afíy = mx + n. m: pendent (el que augmenta la y quan x augmenta 1). n: ordenada a l'origen (0, n).y = 3x + 10: m = 3, n = 10
Lineal i constantLineal: y = mx (passa per l'origen). Constant: y = n (horitzontal).y = 2x · y = 4
Pendent per dos puntsm = y₂ − y₁x₂ − x₁. m > 0 creix · m < 0 decreix.A(1, 3), B(4, 9): m = 63 = 2
Equació de la rectaCalcula m i substitueix un punt a y = mx + n per trobar n.3 = 2 · 1 + n → n = 1 → y = 2x + 1
Tall de dues rectesIguala les dues fórmules.1,5x = 0,5x + 10 → x = 10, y = 15
Funció quadràticay = ax2 + bx + c: paràbola. a > 0 → ∪ (mínim) · a < 0 → ∩ (màxim).y = −x2 + 4x → ∩
Vèrtex i eixxv = −b2a, yv = f(xv). Eix: x = xv.y = x2 − 4x + 3 → V(2, −1)
Talls de la paràbolaEix Y: (0, c) · Eix X: resol ax2 + bx + c = 0.x2 − 4x + 3 = 0 → (1, 0) i (3, 0)
Màxims i mínims en problemesEl valor màxim o mínim és al vèrtex: xv diu quan; yv, quant.h = −5t2 + 20t → màxim als 2 s: 20 m
Proporcionalitat inversay = kx: x · y = k sempre. Hipèrbola; no talla els eixos.y = 120x: x = 20 → y = 6
Exponencialy = a · bx. b > 1 creix · 0 < b < 1 decreix. A cada pas es multiplica per b.y = 500 · 2x → x = 3: 4 000
Quin model?Diferències constants → afí · segones diferències constants → quadràtica · x · y constant → inversa · quocients constants → exponencial.6, 18, 54, 162 (×3) → exponencial
