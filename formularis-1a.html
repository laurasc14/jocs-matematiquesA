ConcepteLa reglaUn exemple
Potènciaan = a · a ··· a (n vegades): a és la base i n, l'exponent.
Compte: el parèntesi canvia el resultat.		24 = 16 · (−3)2 = 9 però −32 = −9
Exponent 0 i negatiua0 = 1 · a−n = 1an
Compte: a−n no és un nombre negatiu.		3−2 = 19 · (12)−3 = 23 = 8
Producte i quocientAmb la mateixa base: am · an = am+n · am : an = am−n.
Compte: amb bases diferents no es pot.		43 · 4−5 = 4−2 = 116 · 65 : 63 = 36
Potència d'una potència(am)n = am · n(52)3 = 56
Potència d'un producte o d'una fracció(a · b)n = an · bn · (ab)−n = (ba)n
Compte: (a + b)2 ≠ a2 + b2.		(2 · 5)3 = 1 000 · (23)−2 = 94
Notació científicaa · 10n amb 1 ≤ a < 10. Grans → n positiu; petits → n negatiu. Calculadora: 3.4E6.3 400 000 = 3,4 · 106 · 0,00072 = 7,2 · 10−4
Operar en notació científica× → es multipliquen i se sumen els exponents · : → es divideixen i es resten. Ajusta perquè 1 ≤ a < 10.
Compte: «quants en caben de sencers» → arrodoneix cap avall.		(4 · 106) · (5 · 10−2) = 20 · 104 = 2 · 105

ConcepteLa reglaUn exemple
Equació de 1r grau1) parèntesis 2) denominadors: × m.c.m. 3) x a un costat 4) aïlla x 5) comprova.3(x − 2) = x + 4 → 2x = 10 → x = 5

Incompleta ax2 + bx = 0Factor comú: x(ax + b) = 0 → x = 0 o l'altra.
Compte: no dividis per x.		x2 − 6x = 0 → x = 0 o x = 6

Problemes1) Què és x? 2) Planteja 3) Resol 4) Comprova i descarta el que no té sentit.x(x + 3) = 28 → x = 4 (−7 no serveix)
Índex de variacióAugment del r % → × (1 + r/100) · descompte del r % → × (1 − r/100).8 € amb −35 % → 8 · 0,65 = 5,20 €
Preu sense IVAPreu amb IVA : 1,21.
Compte: no es resta el 21 %.		24,20 : 1,21 = 20 €
Variacions encadenadesEs multipliquen els índexs.+10 % i −5 %: 1,10 · 0,95 = 1,045 → +4,5 %

InequacionsCom una equació, però si × o : per un negatiu, el signe gira.7 − 4x > 15 → −4x > 8 → x < −2
Solució com a intervalClaudàtor si l'extrem hi entra; parèntesi si no. «Com a mínim» ≥, «com a màxim» ≤.x ≥ 3 → [3, +∞) · x < −2 → (−∞, −2)
Sistema: solució gràficaCada equació és una recta: la solució és el punt de tall. Paral·leles → cap · la mateixa → infinites.x + y = 6 i x − y = 2 → (4, 2)
SubstitucióAïlla una lletra i substitueix-la a l'altra equació.x + 2y = 7, 3x − y = 7: x = 7 − 2y → y = 2, x = 3
IgualacióAïlla la mateixa lletra a les dues i iguala.y = x + 4, y = −2x + 10 → x = 2, y = 6
ReduccióMultiplica perquè una lletra tingui coeficients oposats i suma.x + y = 10, x − y = 4 → 2x = 14 → x = 7, y = 3
